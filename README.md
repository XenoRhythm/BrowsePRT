# BrowsePRT

OPSEC reimplementation of [ROADtoken](https://github.com/dirkjanm/ROADtoken) - BrowserCore invocation via cmd and named pipes i/o redirection.

## Usage

`./browseprt.exe`

For even better opsec, consider placing the binary in program files and renaming it as one of the browsers.
